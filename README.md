# Prime Auto Print (PAP)

Gmail を一定間隔でチェックし、登録した条件（トリガー）に合う**未読**メールが届いたら、
ネットワーク接続のレシートプリンターに自動印刷する Android アプリです。

**このバージョンでの変更点**
- 名称を Prime Auto Print (PAP) に変更
- **トリガーを何件でも登録でき、1件ずつオン／オフできる**ようになりました
  （例: 「出前館 注文」「自社サイト 注文」「予約リマインド」を別々に管理）
- **接続チェック**ボタンを追加。Gmailにログインできたか／未読が何件あったか／
  トリガーごとに何件一致したか／プリンターに送れたかを画面に1行ずつ表示します
- チェック間隔を 5 / 10 / 30 秒から選べます
- 通知をタップするとアプリが開きます

## 事前準備：Gmailの「アプリパスワード」を取得する
通常のGmailパスワードではログインできません（Googleのセキュリティ仕様）。

1. Googleアカウントで [2段階認証](https://myaccount.google.com/security) を有効にする
2. https://myaccount.google.com/apppasswords を開く
3. アプリ名を適当に入力（例: PAP）して「作成」
4. 表示された16桁をアプリの「アプリパスワード」欄に入力（スペースは自動で無視されます）
5. Gmail（Web）→ 設定 → 「メール転送とPOP/IMAP」→ **IMAPを有効にする**

## 使い方
1. Gmailアドレスとアプリパスワードを入力
2. 「トリガー」の**＋ 追加**で条件を登録
   - キーワード（件名または本文に含む）だけ、送信元アドレスだけ、両方、どれでもOK
   - 両方入れると「その送信元から届いた、そのキーワードを含むメール」だけが対象
   - 行をタップすると編集・削除、右のスイッチで**そのトリガーだけ**オン／オフ
3. プリンターのIPアドレスとポート（通常 9100）を入力
4. チェック間隔を選ぶ
5. 「接続チェック」を実行 → OK が並べば設定完了
6. 「監視を開始」をタップ → 常駐通知が出て、間隔ごとにチェックします

### 印刷されないときは「接続チェック」
上から順に、どこで止まっているかが分かります。

- `NG ログインできません` → アプリパスワードが違う／2段階認証がオフ
- `OK 受信トレイを読めました（未読 N件）` → ログインとIMAPは問題なし
- `-- 出前館 注文: 0件一致` → 条件が実際のメールと合っていない
  （**対象メールをすでに既読にしている**のが最も多い原因。未読のみが対象です）
- `NG プリンターに送れません` → IP・ポート・電源・同じWi-Fiかを確認

## 印刷の見た目・文字化け対策
設定画面の「印刷レイアウト」で調整します。

- **本文だけ印刷する**：オンにすると差出人・件名の見出しを省き、メール本文＋時刻だけを印刷します
- **レシート幅**：58mm(32桁) / 80mm(48桁)。選んだ桁数で自動的に折り返すので、右端で文字が切れません
- **文字コード**：日本語が化けるときは Shift_JIS ↔ UTF-8 を切り替えて「文字テスト印刷」を実行。
  ひらがな・カタカナ・漢字・英数・記号・半角カナが全部読めた側が正解です
- 絵文字や ✓ → ① などプリンターのフォントに無い文字は、自動で [OK] や -> に置き換え、
  それでも表示できない文字は落とします（ランダムな文字が出るのを防ぎます）
- 空行が多い注文メールは、3行以上の連続空行を1行にまとめて紙を節約します

> 日本語がどうしても化ける場合、そのプリンターに日本語フォント（漢字ROM）が
> 入っていない可能性があります。その機種では英数のみ印刷可能です。

## APKの作り方（GitHub Actionsでビルド）
1. このフォルダの中身をあなたのリポジトリにそのままコピー
2. commit して push
   ```bash
   git add .
   git commit -m "Prime Auto Print"
   git push origin main
   ```
3. GitHub → 「Actions」タブ → 「Build APK」が自動で走る（数分）
4. 実行結果ページ下部の「Artifacts」に **PAP-debug-apk** が出るのでダウンロード
5. zipを解凍すると `app-debug.apk` が入っています

手動実行: Actions → 「Build APK」→ 「Run workflow」

## インストール
1. `app-debug.apk` を端末に転送してタップ
2. 「提供元不明のアプリ」を許可
3. 通知の許可を求められたら許可（Android 13以降）

## 注意点
- 端末の電源が入っていて、プリンターと同じWi-Fiに繋がっている必要があります
- **バッテリー最適化を外してください**：設定 → アプリ → Prime Auto Print → バッテリー → 「制限なし」。
  これをしないと数時間で監視が止まります
- パッケージ名は `com.sukoon.autoprint` のままです（変えると別アプリとして
  インストールされ、既存の設定が引き継がれません）
- アイコンは仮のものです。`app/src/main/res/drawable/ic_launcher.xml` を差し替えてください
- 印刷が成功したメールは既読になります（二重印刷の防止）。手動で先に既読にすると印刷されません
